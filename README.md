# Regulasi: Simulasi Tata Tertib Organisasi

Repo ini adalah simulasi pengelolaan draf regulasi
menggunakan Git dan GitHub, menerapkan pola version
control untuk dokumen yang bersifat mengikat dan
memerlukan jejak audit yang jelas.

## Struktur Regulasi

- pasal-01-ketentuan-umum.md
- pasal-02-hak-dan-kewajiban.md
- pasal-03-sanksi.md

## Alur Pengesahan

Setiap usulan perubahan pasal diajukan melalui branch
terpisah, direview sebagai Pull Request oleh tim hukum,
dan disahkan melalui proses merge setelah disetujui.
Versi resmi regulasi ditandai melalui git tag dan
GitHub Releases.
